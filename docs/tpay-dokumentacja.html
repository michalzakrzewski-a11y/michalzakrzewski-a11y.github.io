2. Opis Integracji

2.1 Model Płatności

Typ integracji: BLIK Recurring (Model O)
groupId: 150
Cel: Automatyczne pobieranie płatności cyklicznych za subskrypcje karmy dla psów

2.2 Przypadek Użycia

Sklep internetowy GO NATIVE oferuje subskrypcję premium karmy dla psów z automatycznym odnawianiem. Klient wybiera produkty, określa częstotliwość dostawy (od 1 do 16 tygodni) i autoryzuje płatność cykliczną BLIK. System automatycznie pobiera płatności przed każdą zaplanowaną dostawą.

2.3 Korzyści dla Klienta

  • Wygodne automatyczne odnawianie subskrypcji
  • 10% rabatu na pierwszą dostawę
  • 5% stałego rabatu na kolejne dostawy
  • Elastyczna zmiana częstotliwości i produktów
  • Możliwość wstrzymania lub anulowania w dowolnym momencie

5. Struktura Bazy Danych

5.1 Tabela: subscriptions

CREATE TABLE subscriptions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID NOT NULL REFERENCES auth.users(id),
  status VARCHAR DEFAULT 'pending',
  delivery_frequency VARCHAR DEFAULT '4_weeks',
  next_delivery_date TIMESTAMP WITH TIME ZONE NOT NULL,
  total_price DECIMAL(10,2) NOT NULL,
  
  -- Pola TPay BLIK Recurring
  payment_provider VARCHAR DEFAULT 'tpay',
  tpay_blik_alias VARCHAR,
  tpay_alias_status VARCHAR,
  
  -- Zarządzanie płatnościami
  is_first_order BOOLEAN DEFAULT true,
  order_count INTEGER DEFAULT 0,
  failed_payment_count INTEGER DEFAULT 0,
  last_payment_date TIMESTAMP WITH TIME ZONE,
  
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

5.2 Tabela: subscription_items

CREATE TABLE subscription_items (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  subscription_id UUID REFERENCES subscriptions(id) ON DELETE CASCADE,
  product_id UUID REFERENCES products(id),
  product_name VARCHAR NOT NULL,
  product_image VARCHAR NOT NULL,
  price DECIMAL(10,2) NOT NULL,
  quantity INTEGER DEFAULT 1,
  size VARCHAR,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

7. Polityka Rabatów

Zamówienie Rabat Opis
Pierwsze (rejestracja) 10% Rabat powitalny dla nowych subskrybentów
Kolejne (cykliczne) 5% Stały rabat lojalnościowy
Przykład kalkulacji:
Cena produktu: 189,00 zł
Pierwsza płatność: 189,00 × 0,90 = 170,10 zł
Kolejne płatności: 189,00 × 0,95 = 179,55 zł

8. Obsługa Błędów Płatności

8.1 Strategia Retry

  1. Pierwsza próba - 2 dni przed planowaną dostawą
  2. Kolejne próby - codziennie przez 3 dni
  3. Po 3 nieudanych próbach - subskrypcja zostaje automatycznie wstrzymana (status: paused)

8.2 Powiadomienia

  • Email do klienta po każdej nieudanej próbie płatności
  • Email do administratora przy wstrzymaniu subskrypcji
  • Możliwość ręcznego wznowienia subskrypcji przez klienta w panelu
